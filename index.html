Everything on your Mac

A daily-driver launcher with the modern features — and an on-device AI that answers and proposes, but never acts without your word.

Launcher

Fast, keyboard-first

⌥Space to fuzzy-match apps, files, calculator, unit conversion, snippets, quicklinks, emoji, system commands, and window layouts. Select a result, Tab, act on it.

Staged

AI that never auto-runs

Ask a question and get an on-device answer. Ask it to do something — "make a snippet", "set the volume to 30" — and it stages in amber for one-click Accept. It never claims it did what it only proposed.

Web search

Answers, your way

A keyless Wikipedia floor by default, or point it at your own SearXNG for full web search. Only your query leaves; the answer is composed on this Mac.

Clipboard

Local history

⌥⇧C for text, image, HTML, and RTF history — all on this Mac, with an ignore list for sensitive apps.

Windows

Built-in tiling

Arrange the focused window with ⌃⌥ and arrows — halves, quarters, thirds, maximize — no separate app.

Sovereign

No account, ever

No server of ours, no telemetry or crash reporting — not even opt-in. The AI sidecar compiles out entirely. Enforced as first-class test gates.

Get Summon

Install with Homebrew. The 0.6.x build is ad-hoc signed, not yet Apple-notarized — the cask clears the download quarantine so it launches; if macOS still blocks it, open once with right-click → Open.

$brew install --cask naklitechie/tap/summon
