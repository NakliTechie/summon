Agent face — same core, second door

CLI + local socket dispatch the same action bus as the hotkey. Off by default; destructive ops are propose-only — they stage in the UI exactly like an AI proposal, because to the core an agent and a model are the same kind of guest.

$ summon --actor agent window leftHalf --apply
layout leftHalf · frame 0,0 716x900
outcome staged proposalID=<proposal-id>
$ summon settings set agent.search.sensitive.enabled true
ok agent.search.sensitive.enabled=true
$ summon --actor agent clipboard search "invoice"
invoice INV-2026-0841 Netcore PS
$ summon --actor agent clipboard delete c81
outcome staged proposalID=<proposal-id> · destructive — awaiting review in Summon UI
1Enabled only via developer settings; socket mode 0600; every call journaled with actor tag.
2The staged line closes the loop: human, agent, and model all converge on one accept surface. One mechanism, three doors.
